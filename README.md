# **Snowfetch** ❄️  

Snowfetch is a tool similar to **neofetch** or **fastfetch**, providing all the essential information about your computer.  

## **Important Information** ⚠️  
- This program **only works on Linux**.  

## **Installation** 💾  

1. **Download the source code**  
2. ** Install 'make'**
2.1 ** do 'make install'**
3 And that's it.
