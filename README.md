# Welcome to a simple fastfetch like tool.
 # 1 - Downloading 🛜.
  - To download snowfetch you need to clone the repo ->
  `git clone https://github.com/SnowsSky/snowfetch.git`
 # 2 - Installing ⬇️.
   ## 2.1 Dependencies:
    - To run this programme you need : `python`
   ## 2.2 Makefile
    - Run `make install`
 # 3 - Use it
  - You can now use it by doing `snowfetch`.
 # 4 - Documentation
  ## 4.1 - How to use Snowfetch ?
   - Just run `snowfetch` or if you want custom color : `snowfetch --colors <color>`
  ## 4.2 - Remove Snowfetch
    - You just need to do `make uninstall` in the projet's folder.
